\begin{abstract}
Diffusion-prior solvers for Fourier phase retrieval are usually evaluated by running each method several times and reporting, for every metric separately, the run closest to the ground truth.
We ask what this protocol measures and what is achievable without the ground truth.
The standard oversampled Fourier operator has an exact eight-element symmetry group (per-channel $180^\circ$ rotations).
We prove that any selector computed from the measurements alone, and any likelihood-only particle weight, is blind to it, and that for samplers with Gaussian transitions the preference for one orientation is bounded by the transitions' equivariance defect.
Auditing three published solvers on FFHQ, we find that selecting the run with the smallest measurement residual and then applying a zero-shot orientation test recovers $92.6$--$97.5\%$ of the gain of an orientation-aware ground-truth oracle.
Within an image, the residual ranks a correct run ahead of a wrong but measurement-consistent one in $97.6\%$ of pairs, far more often than an imperfect-verifier model with exchangeable ranks assumes; the remaining failures are almost all runs that never approach the image.
Yet two of the three solvers fit the noisy data more closely than the ground truth does, so a residual threshold is a property of the solver and cannot certify a reconstruction.

\end{abstract}
