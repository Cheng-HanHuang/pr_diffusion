\section{Selection protocols in recent work}
\label{sec:suppl-protocols}
\Cref{tab:protocols} lists how recent work selects the reported phase-retrieval results.
In the reference code of DAPS, SITCOM and FAST-DIPS, the reported PSNR, SSIM and LPIPS are each the best of four runs against the ground truth, chosen separately for each metric.
