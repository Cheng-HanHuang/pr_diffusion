**But the generative decomposition misses.** At K=16, the registered \(O_{\rm orbit}\) is **0.8587 [0.7849,0.9292]**, versus **0.750** observed (outside this interval). No clear phase-1/phase-2 class-frequency shift was detected by the planner; the miss should not be attributed to proven seed drift.

The race E1 interval covers the outcome **despite**, not because it explains, both components: overforecasted orbit availability is partly offset by an overly pessimistic *unconditional* orientation-selection loss. This is **not** a conditional-on-realized-composition rank test (unlike the separately reported FFHQ FAST analysis); the source data do not identify whether class-rank weights, CLIP success conditional on image, or the per-image generation mixture is responsible for the remaining difference.

**Implication.** The prospective result favors a **class-sensitive GT-free selection model over exchangeable passing ranks** for the deployed E1 policy, but it does **not validate the full generative model**.
