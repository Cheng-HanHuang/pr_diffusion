## Fixed evaluation rule

For each family, evaluate the **primary panel** at the registered K grid, retaining separately B22, DEV80, and 100:80 pooled for FFHQ. For each preregistered policy, a point is covered exactly when \`lo95 <= observed <= hi95\`, because intervals predict **realized-panel** U-statistics. Count coverage across **E0 and E1_CLIP** for the race versus S2 on the primary panel; report all variants. The registered standardized residual \`abs(observed-point)/max((hi95-lo95)/3.92,0.005)\` breaks ties. Secondary panels, race_tau1 prior sensitivity, and tail variant are disclosed but never promoted to retrospective primary. For ImageNet v2, the frozen comparison concerns E0 alone unless a **separately registered** v2 E1 addendum is available.

Intervals incorporate the **stated parametric model and finite realized-panel simulation**, but not distribution-free high-K identification uncertainty, unknown residual-score-tail misspecification, unmodeled solver dependence, misclassified PSNR/orbit labels, or selection biases from a changed image cohort. A covered point is compatible with the model under this rule, **not proof that its generative assumptions are true**; a miss is a falsification of this predictive interval on that grid, not proof of a single unique physical explanation. Compare rank and class anatomy before attributing mechanism.
