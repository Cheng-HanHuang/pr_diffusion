## 2. Exact implementation walkthrough

Paper: https://arxiv.org/pdf/2603.01591 (ICLR2026), §§2.1–2.6; primary source:
https://github.com/ququlza/FAST-DIPS/blob/a9758b38906b7c7950fa04491f37f6634948db26/main.py

- Pixel sampler `FAST_DIPS.sample` lines 207–310 performs `diffusion_scheduler.num_steps-1` iterations = 150 model calls under T=150 and 151 scheduler nodes. `model.tweedie(xt,sigma)` once per iteration (line245), **outside** ADMM loop. The pretrained U-Net is the expensive prior; measurement-space data correction is only the FFT magnitude operator and VJP/forward differences.
- Prior anchor `x0hat=D_theta(xt,sigma)`, `gamma=sigma**2`. Set `x=x0hat`, `u=0`, `v=A(x0hat)` freshly at every diffusion level (lines248–254). No inner MCMC or extra U-Net evaluation for each ADMM correction.
- ADMM K=2 (lines256–277): x-update approximately minimizes `F(x)=||x-x0hat||²/(2 gamma)+rho*||A(x)-(v-u)||²/2`, via `x_update_autograd` steps S=5, `rho=200`. Image update gradient is `(x-x0hat)/gamma + rho J_A(x)^T(A(x)-(v-u))`. One reverse-mode VJP forms the data gradient; the chosen pixel default `use_exact_jvp=False` uses finite difference `[A(x+eta*g)-A(x)]/eta` with eta=1e-3, not exact JVP. An analytic one-dimensional quadratic-model step size, capped by `alpha_max=1`, is checked by backtracking up to 8 halvings. Because backtracking is capped and the step is then applied even if no descent is found, do not overstate an unconditional implementation-level descent guarantee.
- v-update projection onto Euclidean **ball** `C={z:||z-y||_2 <= epsilon}` in *measurement space*, `v= y + min(1,epsilon/||w-y||)*(w-y)`, `w=A(x)+u` (lines269–275). `u <- u + A(x)-v`. The projection ensures `v in C` but does NOT certify `A(x) in C` at a finite K=2, much less the final reconstructed image.
- **Structural no-op / important simplification:** at start of the **first** k of the two ADMM iterations, `x=x0hat` and `b=v-u=A(x0hat)`, so `g=0` exactly mathematically. Thus 5 first-iteration image gradient steps are redundant except for potential tiny floating/numerical effects; the first substantive change is *measurement projection*, which makes the second image update nontrivial. This also means K=1 as configured is an effective **prior-only/no-measurement-control negative control**, not one useful correction step. Test causally on an isolated branch before changing the original.
- Earlier diffusion steps use `xt <- x0y + sigma_next*N(0,I)`; however at the **LAST** step the exact source has `if is_last_step: xt=x0hat` (lines282–287), explicitly **discarding final-level corrected `x0y`**. This differs from a literal reading of paper Eq.11 that always uses `x0corr`. Test whether final corrected output improves raw reconstruction and/or robustness in a **separate versioned ablation**, not by silently patching baseline.
- `return xt.clamp(-1,1)` means returned terminal is a model-range image, and the original A15 grid stores native float plus both rounded common PNG8 and upstream truncation PNG8. All comparison PSNR uses **raw oriented rounded RGB8 PNG**; 180-degree rotation scores are auxiliary.

## 3. The surprising signed-magnitude feasibility issue

Original fixed model/observation: `A(x) = |centered ortho FFT(pad((x+1)/2))|`, an entrywise **nonnegative** tensor of shape (1,3,384,384), `m=442,368`. The frozen A1 observations are **signed additive Gaussian-noisy magnitudes**, sigma=.05. The initial smoke recorded 38.9% negative measurement coordinates.

For any possible image `x`, since `A(x)>=0` entrywise,
`||A(x)-y||_2 >= ||min(y,0)||_2`.
If the frozen observation's negative-part norm exceeds the scalar `epsilon=0.05` passed to native FAST, the desired hard likelihood constraint `||A(x)-y||_2 <= 0.05` has an **empty feasible set over images**. The projection itself is always defined because its auxiliary variable `v` may be negative, but no image can reach the ball. This is not a claim that FAST code has a bug: the paper explicitly uses a few *approximate* ADMM iterations, and at K=2 it may behave as a softened effective penalty or iterative correction rather than an exact feasible projection.

The nominal Gaussian noise vector has RMS scale .05 and typical Euclidean norm about `.05 sqrt(442368) ~= 33.26`, *far* above epsilon .05. However, noise alone does not prove infeasibility: the negative-coordinate bound is a **deterministic numerical certificate** for each frozen tensor. We have NOT computed this value yet. `scripts/track_a/a15_mechanism_cpu_audit.py` is a zero-GPU, no-GT read-only planned audit across all eight frozen y and all 32 saved final x tensors. It verifies original source hashes, model/measurement SHA and 32 candidate float/Png SHA, computes the negative-part lower bound, terminal `||A(x)-y||` and RMS for each root, native K4 total program-after-import versus sample time, then writes a new isolated receipt `a15_6_mechanism_cpu_audit_v1` only on full PASS. This audit does not prove per-step ADMM residual decay; tracing intermediate steps would need a separate instrumented run.

## 4. What this means scientifically

1. **Main speed mechanism (well-supported):** one expensive U-Net call per diffusion level, short inexpensive differentiable forward-model corrections rather than extra U-Net guidance calls or long MCMC/optimizer loops. GPU architecture further speeds FFTs and model inference, but comparator GPUs and wall-scope must be reconciled.
2. **Likely effective PR-specific behavior (hypothesis to test):** repeated measurements pull the denoiser's output into a correct Fourier basin at intermediate noise levels; re-annealing continues prior-guided exploration rather than ensuring hard feasibility. This could explain both 30–34 dB successes and 10–13 dB failed basins. A1.5 K4 rescues K1 failures in terms of GT oracle, but no GT-free selection mechanism has been demonstrated.
3. **Mechanism risks:** large signed observation coordinates violate the strict nonnegative range of A; fixed epsilon has mismatched global-L2 noise units; K2 contains an initial no-op x-update; final corrected output is ignored; FD step-size and bounded backtracking are not exact global theoretical guarantees. These are **testable** and possibly explain why FAST works in practice despite an apparently unattainable nominal constraint, but a source observation alone is not proof of causation.
4. **Novelty caution:** the central denoiser-anchor+ADMM+projection+analytic step/re-anneal scheme is already published by FAST-DIPS (ICLR2026). We cannot claim it as our contribution, and arbitrary hyperparameter tweaking on exposed eight images would not create a new publication story.
