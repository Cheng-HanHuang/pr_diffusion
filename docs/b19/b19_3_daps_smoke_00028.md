# B19.3 DAPS smoke: image 00028

This note is superseded by:

`docs/b19/b19_3_daps_smoke_special_images.md`

Key result:

Official DAPS with default FFHQ pixel-DDPM phase-retrieval settings fails on image `00028`, with per-run PSNRs approximately:

`13.643, 15.093, 12.375, 12.891`

This was later compared against DAPS smokes on `00013`, `00017`, and `00034`, showing that DAPS works on easier/mixed images but still fails on `00028`.
